# Launch checklist

Items below need a product, legal or operations decision before launch.

| Item                                             | Explanation                                                                                      | Status   |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------ | -------- |
| Set `VITE_PUBLIC_APP_URL` in production          | Enables the canonical URL, absolute sharing-preview image and root sitemap at build time.        | Not done |
| Write and legally review Privacy and Terms pages | Publish both pages, then set `LEGAL_PAGES_READY` to true so their links appear.                  | Not done |
| Decide on pricing wording                        | Do not publish prices until the product pricing is confirmed.                                    | Not done |
| Decide whether to list message languages         | List languages only after native-speaker review of each template.                                | Not done |
| Add a support contact                            | Choose and display a support channel in the product.                                             | Not done |
| Optionally add real product screenshots          | If useful, take screenshots by hand from the demo account; do not use generated or stock images. | Not done |
